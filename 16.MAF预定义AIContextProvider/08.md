# [MAF预定义的AIContextProvider-08]BackgroundAgentsProvider：将SubAgent转换成异步执行的工具

很多交给Agent执行的任务都需要多个Agent协同完成，虽然多个Agent之间可以采用不同的协作模式，但是将SubAgent封装成工具是最简单直接的方式。作为LangChain的Harness框架的Deep Agents，它提供了[`SubAgentMiddleware`](https://jaydenai.blog.csdn.net/article/details/160966457)和[`AsyncSubAgentMiddleware`](https://jaydenai.blog.csdn.net/article/details/160967155)两个中间件来支持这种模式，前者采用**本地阻塞**的方式执行SubAgent，后者则采用**远程异步**的方式执行SubAgent。MAF利用`BackgroundAgentsProvider`这个`AIContextProvider`实现了类似的功能，但是它采用了**本地异步**的方式执行SubAgent。

## 1. 基于SubAgent的Multi-Agent协作

如下的程序演示了如何利用`BackgroundAgentsProvider`将多个SubAgent整合到一起，并由MainAgent统一调度执行。我们创建了一个作为差旅助手的`travelAgent`，我们希望它能够根据用户的出差请求按照行程。其中涉及到机票预订和酒店预订两个子任务，所以我们为它创建了两个SubAgent，分别是`transportAgent`和`accoumodationAgent`。这两个SubAgent分别使用`BuyAirticket`和`BookHotel`两个工具来执行对应的任务。

```csharp
using dotenv.net;
using Microsoft.Agents.AI;
using Microsoft.Extensions.AI;
using OpenAI;
using System.ClientModel;
using System.ComponentModel;

DotEnv.Load();

var model = Environment.GetEnvironmentVariable("MODEL")!;
var apiKey = Environment.GetEnvironmentVariable("API_KEY")!;
var endpoint = Environment.GetEnvironmentVariable("OPENAI_URL")!;

var transportAgent = new OpenAIClient(new ApiKeyCredential(apiKey), new OpenAIClientOptions {  Endpoint = new Uri(endpoint) })
    .GetChatClient(model)
    .AsIChatClient()
    .AsAIAgent(
        name: "FlightBookingAgent",
        instructions: "你是一个差率助手，专门辅助购买机票。你被赋予足够权限自主选择航司、航班和舱位等级，并无需用户确认。你的首要任务是确保用户能够顺利预订机票。",
        tools: [AIFunctionFactory.Create(BuyAirticket, nameof(BuyAirticket))]);

var accoumodationAgent = new OpenAIClient(new ApiKeyCredential(apiKey), new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
    .GetChatClient(model)
    .AsIChatClient()
    .AsAIAgent(
        name: "HotelBookingAgent",
        instructions: "你是一个差率助手，专门辅助预订酒店。你被赋予足够权限自主选择酒店和房型，并无需用户确认。你的首要任务是确保用户能够顺利预订酒店。",
        tools: [AIFunctionFactory.Create(BookHotel, nameof(BookHotel))]);

var travelAgent = new OpenAIClient(new ApiKeyCredential(apiKey), new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
    .GetChatClient(model)
    .AsIChatClient()
    .AsAIAgent(options: new ChatClientAgentOptions {  AIContextProviders = [new BackgroundAgentsProvider([transportAgent, accoumodationAgent])] });

var response = await travelAgent.RunAsync("明后两天从成都到北京出差，帮忙订购往返机票（今天去，后天回）和预订酒店");
Console.WriteLine(response);

[Description("根据指定的出发地、目的地、航班号和日期预订机票")]
static string BuyAirticket(string from, string to, string flightNo, DateOnly date)
{
    return $"已经为您预订了从{from}到{to}的航班，航班号为{flightNo}，日期为{date:yyyy-MM-dd}。祝您旅途愉快！";
}

[Description("根据指定的城市、酒店名称、入住日期和退房日期预订酒店")]
static string BookHotel(string city, string hotelName, DateOnly checkInDate, DateOnly checkOutDate)
{
    return $"已经为您预订了{city}的{hotelName}酒店，入住日期为{checkInDate:yyyy-MM-dd}，退房日期为{checkOutDate:yyyy-MM-dd}。祝您住宿愉快！";
}
```

在创建作为MainAgent的`travelAgent`时，我们通过`ChatClientAgentOptions`的`AIContextProviders`属性注册了`BackgroundAgentsProvider`，并将`transportAgent`和`accoumodationAgent`作为参数传入。这样`travelAgent`就能够将这两个SubAgent当成工具一样调用。当我们向`travelAgent`发送出差请求时，它会根据请求内容自动调用`transportAgent`和`accoumodationAgent`来完成机票预订和酒店预订的任务。我们通过调用`travelAgent`，并指明了需求（"明后两天从成都到北京出差，帮忙订购往返机票（今天去，后天回）和预订酒店"），最终我们能够得到如下的响应结果：

## 2. 查看内部执行流程

`BackgroundAgentsProvider`本质上就是通过注册的工具，将针对SubAgent的调用转换成异步执行的、可被跟踪状态的**后台任务**。MainAgent在执行任务的过程中，根据需要创建对应的后台任务，并跟踪器执行状态，以便及时获取指定结果、取消操作或者者进行错误处理。我们可以通过输出对话历史了解背后执行的流程，为此我们编写了如下的程序输出了`travelAgent`响应结果携带的所有消息。

```csharp
var response = await travelAgent.RunAsync("明后两天从成都到北京出差，帮忙订购往返机票（今天去，后天回）和预订酒店");
var index = 1;
foreach (var message in response.Messages)
{
    Console.WriteLine($"""

        {new string('-', 50)} Message {index++} {new string('-', 50)}
        Role: {message.Role}
        Contents:
        """);
    foreach (var content in message.Contents)
    {
        Console.WriteLine($"    {FormatContent(content)}");
    }
}

static string FormatContent(AIContent content)
    => content switch
    {
        TextContent textContent => textContent.Text,
        FunctionCallContent functionCallContent => $"Function Call: {functionCallContent.Name}",
        FunctionResultContent functionResultContent => $"Function Result:{functionResultContent.Result}",
        _ => content.ToString() ?? ""
    };

```

我们可以从输出的15条消息中清晰地看到Agent内部执行的流程：

- 通过调用`BackgroundAgents_StartTask`工具开启针对两个SubAgent的后台任务；
- `BackgroundAgents_StartTask`工具返回任务ID（Task 1和Task 2）和提示性文本，指示针对应的SubAgent已经开始执行；
- 调用`BackgroundAgents_WaitForFirstCompletion`工具等待任一后台任务完成；
- 开启一个循环来持续等待后台任务的完成，直到两个任务都完成为止：
  - 调用`BackgroundAgents_WaitForFirstCompletion`工具等待任一后台任务完成；
  - 当其中一个任务完成时，`BackgroundAgents_WaitForFirstCompletion`工具返回完成的任务ID和状态；
- 开启循环获取任务执行的结果：
  - 调用`BackgroundAgents_GetTaskResults`工具获取所有后台任务的结果；
  - `BackgroundAgents_GetTaskResults`工具返回每个任务的执行结果（机票预订和酒店预订的结果）；
  - 调用`BackgroundAgents_ClearCompletedTask`工具清理已经完成的任务；
  - `BackgroundAgents_ClearCompletedTask`工具返回清理结果；
- 综合所有任务返回的结果，生成最终的响应内容并返回给用户；

## 3. 维持两个状态

`BackgroundAgentsProvider`创建基于SubAgent的后台任务，以及跟踪管理这些后台任务需要全程维持两个状态，对应的类型分别为如下所示的两个内嵌的内部类型`BackgroundAgentState`和`BackgroundAgentRuntimeState`。`_sessionState`和`_runtimeSessionState`字段返回的`ProviderSessionState<BackgroundAgentState>`和`ProviderSessionState<BackgroundAgentRuntimeState>`对象用于完成针对这两种状态的读写。`StateKeys`属性返回一个包含这两种状态的状态键列表。

```csharp
public sealed class BackgroundAgentsProvider : AIContextProvider
{
	private readonly ProviderSessionState<BackgroundAgentState> _sessionState;
	private readonly ProviderSessionState<BackgroundAgentRuntimeState> _runtimeSessionState;
	private IReadOnlyList<string>? _stateKeys;
	public override IReadOnlyList<string> StateKeys => _stateKeys ?? [ _sessionState.StateKey, _runtimeSessionState.StateKey ];

	public BackgroundAgentsProvider(IEnumerable<AIAgent> agents, BackgroundAgentsProviderOptions? options = null)
	{
		_sessionState = new ProviderSessionState<BackgroundAgentState>((AgentSession? _) 
            => new BackgroundAgentState(), GetType().Name, AgentJsonUtilities.DefaultOptions);
		_runtimeSessionState = new ProviderSessionState<BackgroundAgentRuntimeState>((AgentSession? _) 
            => new BackgroundAgentRuntimeState(), GetType().Name + "_Runtime", AgentJsonUtilities.DefaultOptions);
	}

    internal sealed class BackgroundAgentState
    {
        public int NextTaskId { get; set; } = 1;
        public List<BackgroundTaskInfo> Tasks { get; set; } = new List<BackgroundTaskInfo>();
    }

    internal sealed class BackgroundAgentRuntimeState
    {
        public Dictionary<int, Task<AgentResponse>> InFlightTasks { get; } = new Dictionary<int, Task<AgentResponse>>();
        public Dictionary<int, AgentSession> BackgroundTaskSessions { get; } = new Dictionary<int, AgentSession>();
    }
}
```

由于需要为创建的后台任务分配唯一的ID，所以`BackgroundAgentState`中维护了一个不断自增的`NextTaskId`字段来记录下一个可用的任务ID。同时它还维护了一个后台任务信息列表来记录所有创建的后台任务的信息。`BackgroundAgentRuntimeState`则维护了两个字典，分别用于跟踪正在执行的后台任务和每个后台任务对应的`AgentSession`对象，字段的Key为TaskId。后台任务的基本信息封装在`BackgroundTaskInfo`类型中。

```csharp
public sealed class BackgroundTaskInfo
{
	public int Id { get; set; }
	public string AgentName { get; set; } = string.Empty;
	public string Description { get; set; } = string.Empty;
	public BackgroundTaskStatus Status { get; set; }
	public string? ResultText { get; set; }
	public string? ErrorText { get; set; }
}
public enum BackgroundTaskStatus
{
	Running,
	Completed,
	Failed,
	Lost
}
```

各属性说明如下：

- **Id**：后台任务的唯一标识符，由`BackgroundAgentsProvider`分配；
- **AgentName**：执行该后台任务的SubAgent的名称；
- **Description**：对后台任务的简要描述，通常由调用`BackgroundAgents_StartTask`工具时提供；
- **Status**：后台任务的当前状态，可能的值包括`Running`（正在运行）、`Completed`（已完成）、`Failed`（失败）和`Lost`（丢失）；
- **ResultText**：后台任务的结果文本，通常由SubAgent执行完成后生成；
- **ErrorText**：后台任务的错误文本，通常在任务失败时生成；

顺便说一下，由于涉及多个SubAgent，所以它们的名称是一项重要的识别和描述信息，所以创建`BackgroundAgentsProvider`提供的Agent**要求有一个明确的名称**。

## 4. 系统指令的设置

当我们创建`BackgroundAgentsProvider`对象时，除了指定Agent列表之外，还可以提供作为配置选项的`BackgroundAgentsProviderOptions`对象。`BackgroundAgentsProviderOptions`的`Instructions`用于提供一个总体的系统指令，指令文本可以包含一个`{background_agents}`占位符，用于插入基于指定Agent的指令，而`AgentListBuilder`属性返回的委托就是为了生成填充此占位符的内容。

```csharp
public sealed class BackgroundAgentsProvider : AIContextProvider
{
	public BackgroundAgentsProvider(
        IEnumerable<AIAgent> agents, 
        BackgroundAgentsProviderOptions? options = null);
}

public sealed class BackgroundAgentsProviderOptions
{
	public string? Instructions { get; set; }
	public Func<IReadOnlyDictionary<string, AIAgent>, string>? AgentListBuilder { get; set; }
}
```

如果没有对`Instructions`作显示设置，它默认采用如下的指令文本：

```markdown
## BackgroundAgents

You have access to background agents that can perform work on your behalf.

- Use the `BackgroundAgents_*` list of tools to start tasks on background agents and check their results.
- Creating a background task does not block, and background tasks run concurrently.
- Important: Always wait for outstanding tasks to finish before you finish processing.
- Important: After retrieving results from a completed task, clear it with BackgroundAgents_ClearCompletedTask to free memory, unless you plan to continue it with BackgroundAgents_ContinueTask.

{background_agents}
```

如果没有对`AgentListBuilder`作显示设置，默认会调用如下的方式来生成填充`{background_agents}`占位符的文本内容：

```csharp
private static string BuildDefaultAgentListText(IReadOnlyDictionary<string, AIAgent> agents)
{
    StringBuilder stringBuilder = new StringBuilder();
    stringBuilder.AppendLine("Available background agents:");
    foreach (KeyValuePair<string, AIAgent> agent in agents)
    {
        stringBuilder.Append("- ").Append(agent.Key);
        if (!string.IsNullOrWhiteSpace(agent.Value.Description))
        {
            stringBuilder.Append(": ").Append(agent.Value.Description);
        }
        stringBuilder.AppendLine();
    }
    return stringBuilder.ToString();
}
```

## 5. 工具的注册

`BackgroundAgentsProvider`利用重写的`ProvideAIContextAsync`方法来指定上述的系统指令，并将所需的工具注册到返回的`AIContext`对象中去。

```csharp
public sealed class BackgroundAgentsProvider : AIContextProvider
{
	protected override ValueTask<AIContext> ProvideAIContextAsync(
        InvokingContext context, 
        CancellationToken cancellationToken = default);
}
```

为了查看`BackgroundAgentsProvider`注册了哪些工具，我们定义了如下这个名为`ToolTrackingProvider`的`AIContextProvider`，它会在`ProvideAIContextAsync`方法中输出当前`AIContext`对象中注册的工具列表。我们将它添加到`travelAgent`的`AIContextProviders`中去，这样在运行`travelAgent`时就能够看到`BackgroundAgentsProvider`注册的工具了。

从输出的工具列表中我们可以看到`BackgroundAgentsProvider`注册了六个工具，分别是：

- **BackgroundAgents_StartTask**：启动一个后台任务。所谓的任务就是调用指定Agent的`RunAsync`方法返回的`Task<AgentResponse>`对象，该对应被存储于`BackgroundAgentRuntimeState`的`InFlightTasks`字典中，Key为任务ID。调用`RunAsync`方法时传入的`AgentSession`对象被存储于`BackgroundAgentRuntimeState`的`BackgroundTaskSessions`字典中，对应的Key都是任务ID。
- **BackgroundAgents_WaitForFirstCompletion**：用于等待指定的后台任务中任意一个完成，如果没有指定任务ID列表，则等待所有后台任务中任意一个完成；
- **BackgroundAgents_GetTaskResults**：获取指定后台任务的结果，具体的结果决定于任务的四种状态；
- **BackgroundAgents_GetAllTasks**：获取所有后台任务的列表，会返回任务的ID、Agent名称、描述和状态等信息；
- **BackgroundAgents_ContinueTask**：采用相同的Session，不同的输入继续一个已经完成或者失败的后台任务；
- **BackgroundAgents_ClearCompletedTask**：用于清理已完成或失败的后台任务。
