# [从ReAct到CodeAct-02]基于本地Sandbox的代码解释器

通过CodeAct在LangChain的实现可以看出，CodeAct实现核心就是注册一个**代码解释器工具**来执行LLM生成的代码，同时辅以对用的系统指令指导LLM采用基于代码生成的方式来完成任务。对于MAF来说，针对系统指令和工具的注册属于**输入增强**的范畴，可以利用注册的`AIContextProvider`来实现。在MAF实现CodeAct的`HyperlightCodeActProvider`类型就派生于`AIContextProvider`。

借助于`PythonREPL`，`LangChain`可以在本地执行任意合法的Python代码（见[LLM, Show me the Code!](https://blog.csdn.net/JaydenAI/article/details/161879769)），虽然灵活，但也存在安全风险，因为LLM生成的代码可能包含恶意代码，导致宿主机被攻击或者数据泄露。相比之下，`HyperlightCodeActProvider`却走向另一个极端，它利用Hyperlight提供了基于微型虚拟机（MicroVM）的Sandbox作为执行环境。这是一个受限的执行环境，不仅不能安装额外的Python库，读写文件的目录和请求的网址都需要预先声明。`HyperlightCodeActProvider`注册了一个名为`execute_code`的工具函数，在此Sandbox中执行LLM生成的代码，并将执行结果返回给模型。

## 1. 利用HyperlightCodeActProvider实现CodeAct

`HyperlightCodeActProvider`定义在`Microsoft.Agents.AI.Hyperlight`这个NuGet包中，它它支持JavaScript和WebAssembly这两种Sandbox后端。由于我们使用Python作为代码生成的语言，所以我们选择了基于WebAssembly的Sandbox后端。具体的WebAssembly客户模块（Guest Module）由`Hyperlight.HyperlightSandbox.Guest.Python`这个NuGet包提供。在添加了这两个NuGet包的引用之后，我们将前面[采用LangChain实现的例子](https://blog.csdn.net/JaydenAI/article/details/161879769)改写成MAF的形式。

```csharp
using dotenv.net;
using HyperlightSandbox.Guest.Python;
using Microsoft.Agents.AI;
using Microsoft.Agents.AI.Hyperlight;
using Microsoft.Extensions.AI;
using OpenAI;
using System.ClientModel;
using System.ComponentModel;
using System.Text.Json;

DotEnv.Load();

var model = Environment.GetEnvironmentVariable("MODEL")!;
var apiKey = Environment.GetEnvironmentVariable("API_KEY")!;
var endpoint = Environment.GetEnvironmentVariable("OPENAI_URL")!;

var options = HyperlightCodeActProviderOptions.CreateForWasm(PythonGuestModule.GetModulePath());
var hyperlightProvider = new HyperlightCodeActProvider(options);
hyperlightProvider.AddTools(
    AIFunctionFactory.Create(LookupProductId,name: "LookupProductId"),
    AIFunctionFactory.Create(GetInventory,name: "GetInventory"),
    AIFunctionFactory.Create(TriggerRestockAlarm,name: "TriggerRestockAlarm"));

var agent = new OpenAIClient(
        credential: new ApiKeyCredential(key: apiKey),
        options: new OpenAIClientOptions { Endpoint = new Uri(endpoint) })
    .GetChatClient(model: model)
    .AsIChatClient()
    .AsAIAgent(options: new ChatClientAgentOptions {         
        AIContextProviders = [hyperlightProvider] });

var prompt = "帮我检查‘PC’的库存。如果存储<10，就立刻触发补货预警，并告诉我结果。";

var response = await agent.RunAsync(prompt);
var index = 1;
foreach (var message in response.Messages)
{
    Console.WriteLine($"{new string('-', 20)} Message {index++} {new string('-', 20)}");
    PrintMessage(message);
}

[Description("根据商品名称查询商品ID")]
static string LookupProductId([Description("商品名称")] string name)
    => name switch
    {
        "PC" => "P001",
        "Phone" => "P002",
        _ => throw new ArgumentException( "Unknown prodct")
    };

[Description("根据商品ID查询库存数量")]
static int GetInventory([Description("商品ID")] string product_id)
    => product_id switch
    {
        "P001" => 6,
        "P002" => 20,
        _ => throw new ArgumentException("Unknown prodct")
    };

[Description("触发补货警报")]
static bool TriggerRestockAlarm([Description("商品ID")] string product_id)
{     
    Console.WriteLine($"[内部警报] 商品 {product_id} 库存告急，已自动提交补货申请！");
    return true;
}
```

在上面的程序中，我们依然提供了三个工具函数（`LookupProductId`、`GetInventory`和`TriggerRestockAlarm`）分别用于查询商品ID、获取库存数量和触发补货警报。我们调用`HyperlightCodeActProviderOptions`的`CreateForWasm`方法来创建一个适用于`WebAssemblySandbox`的配置对象，并将`PythonGuestModule`的路径传入其中。然后我们根据这个配置选项创建了一个`HyperlightCodeActProvider`对象，并将这三个工具函数注册到这个对象中。接下来我们创建了一个基于`OpenAIClient`的`AIAgent`，并。在调用`AsAIAgent`扩展方法时，我们将`HyperlightCodeActProvider`作为`AIContextProvider`注册到指定的`ChatClientAgentOptions`中。最后我们调用Agent的`RunAsync`方法来执行任务，并调用如下这个`PrintMessage`方法打印出每一轮的消息。

```csharp
static void PrintMessage(ChatMessage message)
{
    Console.WriteLine($"Role: {message.Role}");
    Console.WriteLine("Contents:");
    foreach (var content in message.Contents ?? [])
    {
        switch (content)
        {
            case FunctionCallContent call:
                Console.WriteLine($"{new string(' ', 4)}FunctionCall");
                Console.WriteLine($"{new string(' ', 8)}Name:  {call.Name}");
                Console.WriteLine($"{new string(' ', 8)}CallId: {call.CallId}");
                if (call.Arguments is not null)
                {
                    Console.WriteLine($"{new string(' ', 8)}Arguments");
                    foreach (var (k, v) in call.Arguments)
                    {
                        Console.WriteLine($"{new string(' ', 12)}{k} = {v}");
                    }
                }
                break;
            case FunctionResultContent result:
                Console.WriteLine($"{new string(' ', 4)}FunctionResult:");
                string resultString;

                if (result.Result is JsonElement jeResult && jeResult.ValueKind == JsonValueKind.String)
                {
                    resultString = jeResult.GetString()!;
                }
                else
                {
                    resultString = $"\"{result.Result}\"";
                }

                foreach (var line in resultString.Split(Environment.NewLine))
                {
                    Console.WriteLine($"{new string(' ', 8)}{line}");
                }
                break;
            case TextContent text:
                Console.WriteLine($"{new string(' ', 4)}Text: {text.Text}");
                break;
        }
    }
}
```

```python
if inventory < 10:
    call_tool('TriggerRestockAlarm', product_id=product_id)
    result['restock_triggered'] = True
print(result)
```

## 2. Hyperlight Sandbox详解

要了解`HyperlightCodeActProvider`的设计和实现原理，就得先了解一下Hyperlight提供的Sandbox。Hyperlight是微软开源的一个轻量级的Sandbox框架，它提供了一个安全、隔离的环境来执行指定的代码。Hyperlight提供的Sandbox通过如下这个`Sandbox`类来表示。我们不能直接创建此对象，因为它的构造函数是`internal`的。

```csharp
public sealed class Sandbox : IDisposable
{    
    public const int MaxCodeSize = 10485760;
    public string? OutputPath

    internal Sandbox(
        string? modulePath, ulong heapSize, ulong stackSize, string? inputDir, 
        string? outputDir, bool tempOutput, SandboxBackend backend = SandboxBackend.Wasm);
}

public enum SandboxBackend
{
    Wasm,
    JavaScript
}
```

构造函数参数说明如下：

- **modulePath**：指定了Sandbox执行的客户模块的路径。客户模块是一个预编译的WebAssembly二进制文件，包含了Sandbox中可用的函数和资源。在CodeAct的场景中，这个客户模块就是`PythonGuestModule`，它提供了一个可以执行Python代码的环境；
- **heapSize**和**stackSize**：分别指定了Sandbox的堆内存和栈内存的大小。这些参数用于限制Sandbox中代码的内存使用，以防止恶意代码占用过多资源导致系统崩溃；
- **inputDir**和**outputDir**：分别指定了Sandbox的输入目录和输出目录。Sandbox中的代码可以从输入目录读取文件，也可以将结果写入输出目录;
- **tempOutput**：指定了Sandbox的输出目录是否为临时目录。如果设置为`true`，Sandbox会在执行完成后自动删除输出目录中的文件；如果设置为`false`，输出目录中的文件会被保留，供后续使用或调试；
- **backend**：指定了Sandbox的后端类型，支持Wasm和Js两种后端。Wasm后端使用WebAssembly来执行代码，适用于需要执行多种编程语言的场景；Js后端使用JavaScript引擎来执行代码，适用于只需要执行JavaScript代码的场景。

Sandbox类还提供了一个名为`RegisterTool`的方法，用于向Sandbox中注册工具函数。通过调用这个方法，我们可以将一些预定义的函数注入到Sandbox环境中，使得LLM生成的代码可以直接调用这些函数来完成特定的任务。`RegisterTool`方法有多个重载版本，支持采用不同的委托类型来表示回调的工具函数。`AllowDomain`方法的作用是管理Sandbox执行代码可以访问的**网络白名单**。默认情况下，为了防止大模型生成的代码携带恶意后门、泄露宿主机机密数据或滥用网络，Sandbox内部是处于完全断网状态的。`AllowDomain` 是宿主机主动为Sandbox开辟安全网络通道的唯一口子。

```csharp
public sealed class Sandbox : IDisposable
{    
    public void RegisterTool<TArgs, TResult>(
        string name, 
        Func<TArgs, TResult> handler);
    public void RegisterToolAsync<TArgs, TResult>(
        string name, 
        Func<TArgs, Task<TResult>> handler) ;
    public void RegisterTool(
        string name, 
        Func<string, string> handler);
    public void RegisterToolAsync(
        string name, 
        Func<string, Task<string>> handler);   
    public void AllowDomain(string target, IReadOnlyList<string>? methods = null);   
}
```

我们可以调用`Run`和`RunAsync`方法以同步和异步的方式执行指定的代码字符串，并获取执行结果。表示执行结果的`ExecutionResult`封装了代码执行后的标准输出（`Stdout`）、标准错误（`Stderr`）和退出代码（`ExitCode`）三个属性。通过检查`ExitCode`是否为0，我们可以判断代码是否成功执行。

```csharp
public sealed class Sandbox : IDisposable
{    
    public ExecutionResult Run(string code);
    public Task<ExecutionResult> RunAsync(
        string code, 
        CancellationToken cancellationToken = default);
    public IReadOnlyList<string> GetOutputFiles();
}
public sealed record ExecutionResult(string Stdout, string Stderr, int ExitCode)
{
    public bool Success => ExitCode == 0;
}
```

`Sandbox`类还提供了`Snapshot`/`SnapshotAsync`和`Restore`/`RestoreAsync`方法，用于创建和恢复Sandbox的快照。通过调用`Snapshot`/`SnapshotAsync`方法，我们可以创建一个`SandboxSnapshot`对象来保存当前Sandbox的状态；通过调用`Restore`/`RestoreAsync`方法，我们可以将Sandbox恢复到之前保存的状态。

```csharp
public sealed class Sandbox : IDisposable
{    
    public SandboxSnapshot Snapshot();
    public Task<SandboxSnapshot> SnapshotAsync(CancellationToken cancellationToken = default);
    public void Restore(SandboxSnapshot snapshot);
    public Task RestoreAsync(
       SandboxSnapshot snapshot, 
       CancellationToken cancellationToken = default);    
}

public sealed class SandboxSnapshot : IDisposable
{
    public bool IsDisposed {get;}
    public void Dispose();
}
```

### 2.1 Sandbox的构建

`SandboxBuilder`是一个用于构建`Sandbox`对象的辅助类。`SandboxBuilder`提供了一系列的链式方法来设置`Sandbox`的各种参数，最后通过调用`Build`方法来创建`Sandbox`对象。

```csharp
public sealed class SandboxBuilder
{
    public SandboxBuilder WithBackend(SandboxBackend backend);
    public SandboxBuilder WithModulePath(string path);
    public SandboxBuilder WithHeapSize(string size);
    public SandboxBuilder WithHeapSize(ulong bytes);
    public SandboxBuilder WithStackSize(string size);
    public SandboxBuilder WithStackSize(ulong bytes);
    public SandboxBuilder WithInputDir(string path);
    public SandboxBuilder WithOutputDir(string path);
    public SandboxBuilder WithTempOutput(bool enabled = true);
    public Sandbox Build();
}
```

一系列的`WithXxx`方法说明如下：

- **WithBackend**：设置后端类型，支持Wasm和JavaScript两种后端；
- **WithModulePath**：设置Sandbox执行的客户模块的路径；
- **WithHeapSize**：设置堆内存大小，支持以字符串（如"10MB"）或以字节为单位的数值来指定大小；
- **WithStackSize**：设置栈内存大小，支持以字符串（如"1MB"）或以字节为单位的数值来指定大小；
- **WithInputDir**：设置输入目录路径；
- **WithOutputDir**：设置输出目录路径；
- **WithTempOutput**：设置输出目录是否为临时目录，如果设置为true，Sandbox会在执行完成后自动删除输出目录中的文件；如果设置为false，输出目录中的文件会被保留，供后续使用或调试。

`Hyperlight.HyperlightSandbox.Guest.Python`这个NuGet包提供了针对不同平台（`win-x64`和`linux-x64`）预编译好的Python客户模块（`python-sandbox.aot`）。它提供的`PythonGuestModule`类利用静态方法`GetModulePath`返回Python客户模块的路径。它为`SandboxBuilder`提供了一个扩展方法`WithPythonModule`，调用此方法可以快速地将Python客户模块配置到`SandboxBuilder`中。

```csharp
public static class PythonGuestModule
{
    public const string ModuleFileName = "python-sandbox.aot";
    public static string GetModulePath();
    public static SandboxBuilder WithPythonModule(this SandboxBuilder builder);
}
```

## 2.2 查看预装的Python库

由于Hyperlight Sandbox是一个受限的执行环境，它不允许安装额外的Python库，基本上也不提供网络访问的能力。如果生成的代码需要导入一些没有预装的库，那么就会导致代码执行失败。我们可以通过如下的Python代码片段来查看一下Hyperlight Python客户模块中预装了哪些Python库。

```csharp
using HyperlightSandbox.Api;
using HyperlightSandbox.Guest.Python;

var result = new SandboxBuilder()
    .WithPythonModule()
    .Build()
    .Run("""
    import sys  
    print(sys.builtin_module_names)
    """);
Console.WriteLine($"""
    Built-in modules:
    {result.Stdout}
    """);
```

输出：

从输出结果可以看出，预装的大都是一些底层的Python库。直接利用它们，你可以进行许多底层的系统级开发、性能优化和数据处理：

- 系统控制与性能调优监测内存泄漏：
  - 利用gc垃圾回收和`_tracemalloc`跟踪内存分配，找出程序中的内存漏洞；
  - 排查死锁与崩溃：使用`faulthandler`在程序崩溃时打印出线程的堆栈信息，利用`_thread` 进行底层多线程控制；
  - 系统配置与诊断：通过`sys`和`_sysconfig` 获取当前操作系统、解释器版本的配置参数。
- 高性能计算与数据结构极速数学运算：
  - 利用`math`和`cmath`（复数运算）进行高精度、底层的数字计算；
  - 高效迭代生成：使用`itertools`生成排列组合、无限循环等高性能迭代器，节省内存；
  - 底层数组操作：利用`array`模块存储紧凑的同类型原始数字，比普通的Python列表更省内存、速度更快。
- 网络、安全与数据解析网络套接字编程：
  - 利用`_socket`和`select`编写底层的TCP/UDP服务器，或实现多路复用网络通信；
  - 加密与哈希校验：使用`_md5`、`_sha1`、`_sha2`、`_sha3`以及`_hmac`进行密码加密、文件完整性校验和安全签名；
  - 高效数据序列化：利用`_json`、`_csv`、`_pickle`和`marshal` 对数据进行快速的读取、写入与对象序列化；
  - 解析XML/HTML：通过`pyexpat`和`_elementtree`极速解析XML文档结构。
- 文本处理与国际化字符编码转换：
  - 利用`_codecs_cn`、`_codecs_jp` 等模块处理中日韩等多国语言的复杂文本编码；
  - 时间与时区计算：通过 `_datetime`和`_zoneinfo` 处理全球不同时区的高精度时间转换。
- 核心文件读写与控制底层二进制流操作：
  - 利用`_io` 模块，直接控制文件的缓冲区大小，进行高效率的文本或二进制数据读写；
  - 文件状态与权限检查：使用`_stat`和`posix` 模块，读取文件的元数据。你可以获取文件大小、创建时间，或者检查文件是否具有可读、可写、可执行的权限。
- 特定格式文件解析配置与数据表格读写：
  - 利用`_json` 和`_csv` 模块，以极快的速度解析和生成JSON配置文件或CSV数据表格；
  - XML文档极速处理：通过`pyexpat`和`_elementtree`，高效读取、修改和输出结构复杂的XML文件；
  - SQLite数据库操作：利用`_sqlite3`，直接读写本地轻量级数据库文件，进行复杂的结构化数据存储和查询。
- 压缩、安全与高级传输文件压缩与解压：
  - 使用`zlib` 模块，对大文件进行在线压缩读写，或者直接处理 .gz 格式的压缩数据流，节省磁盘空间；
  - 二进制结构体打包：利用`_struct`和`binascii`，将Python数据转换为C语言风格的二进制字节流，用于读写特定的加密文件或自定义的二进制文件格式；
  - 数据序列化保存：通过`_pickle`和`marshal`，将Python的对象、变量甚至编译后的代码直接保存为本地文件，并在需要时完整还原。

可以看出，虽然通过`_socket`和`select`提供了网络编程的能力，但是并没有`Httpx`、`Requests`等更高级的HTTP库，也没有像`Pandas`和`NumPy`这样的数据分析和科学计算库，更没有`matplotlib`这种功能强大的数据可视化库。如果需要这些功能，只能利用注册的工具函数来实现相应的功能。

## 2.3 文件读写和工具调用

下面这个简单的实例演示了HyperLight Sandbox的文件读写和工具调用功能。我们创建了一个`input`和`output`目录作为Sandbox的输入输出目录，并在input目录中创建了一个名为`city.txt`的文件，写入了一个城市名称`chengdu`。然后我们创建了一个Sandbox对象，并注册了一个名为`get_weather`的工具函数，这个函数会根据传入的城市名称调用一个天气API来获取天气信息。接下来我们编写了一段Python代码，在Sandbox中执行这段代码。代码的逻辑：先从输入文件中读取城市名称，然后调用工具函数获取天气信息，最后将天气信息写入输出文件中,最后再从输出文件中读取天气信息并打印出来。

```csharp

{
    Directory.CreateDirectory("input");
    File.WriteAllText("input/city.txt", "chengdu");
}
if (!Directory.Exists("output"))
{
    Directory.CreateDirectory("output");
}

    .WithPythonModule()
    .WithInputDir("input") 
    .WithOutputDir("output")
    .Build();

sandbox.RegisterTool("get_weather", async (WeatherArgs args) =>
{
    return httpClient.GetStringAsync($"https://uapis.cn/api/v1/misc/weather?city={args.city}");
});

with open('/input/city.txt', 'r') as f:
    city = f.read()
print(f'- 1. read city from input/city.txt: {city}\n')
```

## 3. HyperlightCodeActProviderOptions

`HyperlightCodeActProviderOptions`是一个用于配置`HyperlightCodeActProvider`的选项类。如果直接调用构造函数，我们只能使用默认的`JavaScriptSandbox`后端的`HyperlightCodeActProviderOptions`。如果想要使用`WebAssemblySandbox`后端来执行Python代码，就需要调用`CreateForWasm`方法，通过指定Python客户模块的路径来对应的`HyperlightCodeActProviderOptions`对象。`CreateForJavaScript`方法则是创建一个适用于`JavaScriptSandbox`后端的`HyperlightCodeActProviderOptions`对象。对应的后端和客户模块通过只读属性`Backend`和`ModulePath`暴露出来。

```csharp
public sealed class HyperlightCodeActProviderOptions
{
    public HyperlightCodeActProviderOptions()
        : this(SandboxBackend.JavaScript, modulePath: null)
    {
    }

    public SandboxBackend Backend { get; };
    public string? ModulePath { get; };

    private HyperlightCodeActProviderOptions(SandboxBackend backend, string? modulePath);
    public static HyperlightCodeActProviderOptions CreateForWasm(string modulePath);
    public static HyperlightCodeActProviderOptions CreateForJavaScript();
}
```

`HyperlightCodeActProviderOptions`提供了如下的可读写属性来定制化`Sandbox`的行为：

```csharp
public sealed class HyperlightCodeActProviderOptions
{    
    public string? HeapSize { get; set; };
    public string? StackSize { get; set; };
    public IEnumerable<AIFunction>? Tools { get; set; };
    public CodeActApprovalMode ApprovalMode { get; set; } = CodeActApprovalMode.NeverRequire;;
    public string? HostInputDirectory { get; set; };
    public IEnumerable<FileMount>? FileMounts { get; set; };
    public IEnumerable<AllowedDomain>? AllowedDomains { get; set; }
}

public enum CodeActApprovalMode
{
    AlwaysRequire,
    NeverRequire,
}
```

配置属性说明如下：

- **HeapSize**和**StackSize**：分别指定了`Sandbox`的堆内存和栈内存的大小，以字符串的形式表示，如"10MB"、"1GB"等；
- **Tools**：指定了要注册到`Sandbox`中的工具函数列表，每个工具函数都是一个`AIFunction`对象，包含了工具函数的名字、描述和回调函数等信息；
- **ApprovalMode**：指定了CodeAct的审批模式，支持`AlwaysRequire`和`NeverRequire`两种模式。在`AlwaysRequire`模式下，每次LLM生成的代码都需要经过人工审批才能执行；在`NeverRequire`模式下，LLM生成的代码会被自动执行，无需人工审批。默认值为`NeverRequire`；
- **HostInputDirectory**：指定了`Sandbox`的输入目录在宿主机上的路径；
- **FileMounts**：指定了要挂载到`Sandbox`中的文件列表，每个文件都是一个`FileMount`对象，包含了文件在宿主机上的路径和在`Sandbox`中的路径等信息；
- **AllowedDomains**：指定了`Sandbox`内AI代码的**网络访问白名单**，每个允许的域都是一个`AllowedDomain`对象，包含了域名和允许访问的方法列表等信息。

可以看出，`HyperlightCodeActProviderOptions`提供并没有提供针对输出目录和`TempOutput`的配置选项，可以认为它构建的是一个绝对安全的只读的`Sandbox`环境，完全不修改宿主的文件系统。通过前面对`SandBox`的介绍，我们知道`SandBox`只提供输入、输出和临时输出目录的设置，并不曾提供所谓的文件/目录挂载的功能，但是`HyperlightCodeActProviderOptions`提供了`FileMounts`这个属性，这个设置有两个作用：

- 为注册的代码执行工具提供相应的描述，让LLM知道`Sandbox`目前的目录布局；
- 如果设置了所谓的目录挂载，`SandBox`的`TempOutput`需要设置为true，这样`Sandbox`会在执行完成后自动删除输出目录中的文件。

## 4. HyperlightCodeActProvider

派生于`AIContextProvider`的`HyperlightCodeActProvider`根据指定的`HyperlightCodeActProviderOptions`创建而成。它的使命就是通过重写的`ProvideAIContextAsync`方法动态注册用于执行代码的工具函数和提供相应的系统指令。除了这个核心方法之外，`HyperlightCodeActProvider`还提供了一系列的方法来管理注册到`Sandbox`中的工具函数、文件挂载和允许访问的域。

```csharp
public sealed class HyperlightCodeActProvider : AIContextProvider, IDisposable
{    
    public HyperlightCodeActProvider(HyperlightCodeActProviderOptions? options = null);

    public void AddTools(params AIFunction[] tools);
    public IReadOnlyList<AIFunction> GetTools();
    public void RemoveTools(params string[] names);
    public void ClearTools();
    
    public void AddFileMounts(params FileMount[] mounts);
    public IReadOnlyList<FileMount> GetFileMounts();
    public void RemoveFileMounts(params string[] mountPaths);
    public void ClearFileMounts();
    
    public void AddAllowedDomains(params AllowedDomain[] domains);
    public IReadOnlyList<AllowedDomain> GetAllowedDomains();
    public void RemoveAllowedDomains(params string[] targets);

    protected override ValueTask<AIContext> ProvideAIContextAsync(
        InvokingContext context, 
        CancellationToken cancellationToken = default)
}
```

为了避免针对`SandBox`的重复创建，同时又要即使应用通过上述这些方法针对配置选项的更新，`HyperlightCodeActProvider`在内部为这些配置选项生成一个**指纹**。配置的变更会导致指纹的改变，`HyperlightCodeActProvider`会通过比较指纹的方式来决定是否需要重新创建`Sandbox`实例。
