# [对比学习LangChain和MAF-17]Harness在LangChain和MAF中的应用

**Harness Engineering**在MAF中是通过**HarnessAgent**这个Agent中间件来实现的，它整合了一系列用来实现相应Harness手段的组件，包括三大中间件（AIFunction、ChatClient和Agent中间件）和若干**AIContextProvider**，在[12.DeepAgents:LC的Harness](https://blog.csdn.net/jaydenai/category_13163101.html)系列文章中对此有系统的介绍。在LangChain体系与之对标的自然就是**DeepAgents**，`create_deep_agent`函数通过将一系列实现对应Harness手段的中间件。其实两者总体实现差不多，但是很多细节上也有不小的差异。本篇文章内容简单，我们分别使用默认的配置分别创建一个`HarnessAgent`和`deep_agent`，看看它们对同一个问题的解决方式有什么不同。

## 1. DeepAgents

我们直接使用[LangChain QuickStart](https://docs.langchain.com/oss/python/langchain/quickstart#deep-agents)提供的例子：利用自定义工具函数从网络读取《了不起的盖茨比》全本，从中统计提及`Gatsby`的行数和第一次提到`Daisy`的行号，并用两句化概括整本书的内容。如下面的代码所示，我们在调用`create_deep_agent`函数的时候，仅指定了必要的四个参数：

- **model**：调用LLM的语言组件；
- **tools**：注册用于读取网络资源内容的工具函数`fetch_text_from_url`;
- **system_prompt**: 指导LLM工作的系统提示词；
- **checkpointer**： 用于持久化的`InMemorySaver`对象。

```python
import urllib.request
from langchain.tools import tool
from langgraph.checkpoint.memory import InMemorySaver
from langchain_openai  import ChatOpenAI
from deepagents import create_deep_agent
from dotenv import load_dotenv

load_dotenv()

@tool
def fetch_text_from_url(url: str) -> str:
    """读取执行URL对应文本资源的内容
    """
    req = urllib.request.Request(
        url,
        headers={"User-Agent": "Mozilla/5.0 (compatible; quickstart-research/1.0)"},
    )

    with urllib.request.urlopen(req, timeout=120) as resp:
        raw = resp.read()
    return raw.decode("utf-8", errors="replace")

SYSTEM_PROMPT = """\
您是一位文学数据助手。
## 可用工具 
- `FetchTextFromUrl`：从 URL 加载文档文本到对话中。

请勿猜测行数或位置——请根据已保存文件的工具处理结果进行判断。"""

 2）文件中第一行包含**Daisy**的行号是多少（从1开始计数）。
 3）用两句话概括全文。

 请尽力完成 (1) 和 (2)。
 如果您发现无法使用现有工具和推理方法**验证**确切答案，请不要捏造数字：在该字段中使用 `null`，并在 `how_you_computed_counts` 中详细说明限制。
 如果您遇到任何错误，请报告错误内容和错误信息。"""

agent = create_deep_agent(
    model=ChatOpenAI(model="gpt-5.4-mini"),
    tools=[fetch_text_from_url],
    system_prompt=SYSTEM_PROMPT,
    checkpointer= InMemorySaver(),
)

  
result = agent.invoke(
    {"messages": [{"role": "user", "content": prompt}]},
    config={"configurable": {"thread_id": "great-gatsby-da"}},
)
for msg in result.get("messages"):
    msg.pretty_print()
```

## 2. HarnessAgent

可以看出采用默认配置调用`create_deep_agent`完美完成了我们给出的三项任务，现在我们看看同样采用默认配置创建的`HarnessAgent`是否也一样。由于我们希望通过消息列表分析整个推理和处理流程，我们针对`ChatMessage`类型定义了如下这个`PrettyPrint`扩展方法，将它的内容以类似于上面的格式输出。

```csharp
public static class Extensions
{
    public static void PrettyPrint(this ChatMessage message)
    {
        Console.WriteLine($"{new string('-', 30)}{message.Role} message {new string('-', 30)}");
        var functionCallContents = message.Contents.OfType<FunctionCallContent>().ToArray();
        if (functionCallContents.Length != 0)
        {
            Console.WriteLine("Function Calls:");
            foreach (var content in functionCallContents)
            {
                var arguments = content.Arguments ?? new Dictionary<string, object?>();
                Console.WriteLine($"""
                            Name: {content.Name}
                            CallId: {content.CallId}
                            Arguments: {string.Join(", ", arguments.Select(it => $"{it.Key}={it.Value}"))}
                        """);
            }
        }

        var functionResultConents = message.Contents.OfType<FunctionResultContent>().ToArray();
        if (functionResultConents.Length != 0)
        {
            Console.WriteLine("Function Results:");
            foreach (var content in functionResultConents)
            {
                Console.WriteLine($"""
                            CallId: {content.CallId}
                            Result: {content.Result?.ToString()?.Truncate()}
                        """);
            }
        }

        var textContents = message.Contents.OfType<TextContent>().ToArray();
        if (textContents.Length != 0)
        {
            foreach (var content in textContents)
            {
                Console.WriteLine(content.Text);
            }
        }
    }
    public static string Truncate(this string? input)
    {
        if (string.IsNullOrEmpty(input))
        {
            return string.Empty;
        }
        return input.Length <= 50 ? input : $"{input.Substring(0, 50)}...";
    }
}
```

```csharp
static async Task<string> FetchTextFromUrlAsync([Description("文本资源地址")]string url)
{
```
