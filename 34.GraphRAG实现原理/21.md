# [GraphRAG实现原理-21]探索Global Search在Map和Reduce阶段的LLM调用

[GraphRAG实现原理-20:四种查询方式之四：Global Search](https://jaydenai.blog.csdn.net/article/details/170018987)详细介绍了作为搜索引擎的`GlobalSearch`，了解了Global Search查询模式的执行流程。这篇文章会补充剩下的内容，进一步了解命令行`graphrag query --method global`内部如何创建`GlobalSearch`对象，并利用它来完成基于Global Search模式的搜索。我们还会通过一个演示程序探索在一个典型的搜索场景中，Map和Reduce两个阶段会进行怎样的LLM调用。

## 1. 执行引擎的创建

GraphRAG最终利用如下这个`get_global_search_engine`函数根据指定的配置和相关参数创建作为搜索引擎的`GlobalSearch`对象，此函数的参数说明如下：

- **config**：GraphRAG全局配置对象，提供补全模型、分词器、Global Search 各项参数（`global_search`段）与并发请求数等。
- **reports**：加载索引表`community_repprts`得到的社区报告列表，作为 Global Search 的上下文数据来源。
- **entities**：加载索引表`entities`得到的实体列表，传入`GlobalCommunityContext`，用于计算社区权重等。
- **communities**：加载索引表`communities`得到社区层级结构列表，供动态社区选择沿层级遍历使用。
- **response_type**：期望的最终回答形态，传给Reduce阶段提示词控制输出风格。
- **dynamic_community_selection**：是否启用动态社区选择；为真时组装`dynamic_community_selection_kwargs`并传入上下文构建器。
- **map_system_prompt**：Map阶段系统提示词；未传时由`GlobalSearch`使用默认模板。
- **reduce_system_prompt**：Reduce阶段系统提示词；未传时由`GlobalSearch`使用默认模板。
- **general_knowledge_inclusion_prompt**：允许通用知识时追加到Reduce阶段提示词的说明；未传时使用默认模板。
- **callbacks**：查询回调列表，用于在Map/Reduce各阶段及流式token生成时触发钩子。

```python
def get_global_search_engine(
    config: GraphRagConfig,
    reports: list[CommunityReport],
    entities: list[Entity],
    communities: list[Community],
    response_type: str,
    dynamic_community_selection: bool = False,
    map_system_prompt: str | None = None,
    reduce_system_prompt: str | None = None,
    general_knowledge_inclusion_prompt: str | None = None,
    callbacks: list[QueryCallbacks] | None = None,
) -> GlobalSearch:
    model_settings = config.get_completion_model_config(
        config.global_search.completion_model_id
    )
    model = create_completion(model_settings)
    model_params = model_settings.call_args
    tokenizer = model.tokenizer
    gs_config = config.global_search

    dynamic_community_selection_kwargs = {}
    if dynamic_community_selection:
        dynamic_community_selection_kwargs.update({
            "model": model,
            "tokenizer": tokenizer,
            "keep_parent": gs_config.dynamic_search_keep_parent,
            "num_repeats": gs_config.dynamic_search_num_repeats,
            "use_summary": gs_config.dynamic_search_use_summary,
            "concurrent_coroutines": config.concurrent_requests,
            "threshold": gs_config.dynamic_search_threshold,
            "max_level": gs_config.dynamic_search_max_level,
            "model_params": {**model_params},
        })

    return GlobalSearch(
        model=model,
        map_system_prompt=map_system_prompt,
        reduce_system_prompt=reduce_system_prompt,
        general_knowledge_inclusion_prompt=general_knowledge_inclusion_prompt,
        context_builder=GlobalCommunityContext(
            community_reports=reports,
            communities=communities,
            entities=entities,
            tokenizer=tokenizer,
            dynamic_community_selection=dynamic_community_selection,
            dynamic_community_selection_kwargs=dynamic_community_selection_kwargs,
        ),
        tokenizer=tokenizer,
        max_data_tokens=gs_config.data_max_tokens,
        map_llm_params={**model_params},
        reduce_llm_params={**model_params},
        map_max_length=gs_config.map_max_length,
        reduce_max_length=gs_config.reduce_max_length,
        allow_general_knowledge=False,
        json_mode=False,
        context_builder_params={
            "use_community_summary": False,
            "shuffle_data": True,
            "include_community_rank": True,
            "min_community_rank": 0,
            "community_rank_name": "rank",
            "include_community_weight": True,
            "community_weight_name": "occurrence weight",
            "normalize_community_weight": True,
            "max_context_tokens": gs_config.max_context_tokens,
            "context_name": "Reports",
        },
        concurrent_coroutines=config.concurrent_requests,
        response_type=response_type,
        callbacks=callbacks,
    )
```

`get_global_search_engine`函数采用如下的流程完成`GlobalSearch`对象的创建：

- 调用`create_completion`函数根据配置创建作为`Completion`模型的`LLMCompletion`对象；
- 提取`LLMCompletion`对象的`Tokenizer`；
- 如果通过`dynamic_community_selection`参数开启了动态社区筛选，则`LLMCompletion`、`Tokenizer`和针对动态社区筛选的配置创建对应的参数字典`dynamic_community_selection_kwargs`；
- 根据参数提供的社区报告、实体和社区列表，以及`Tokenizer`和动态社区筛选的开关和参数字段创建`GlobalCommunityContext`对象，后者为Map节点构建调用LLM的上下文；
- 根据`LLMCompletion`和`GlobalCommunityContext`和相关配置创建返回的`GlobalSearch`对象。

## 2. 两种调用方式

`graphrag query --method global`命令行最终会根据`--streaming`参数选择调用`global_search`或者`global_search_streaming`函数来执行Global search。`global_search_streaming`函数的定义如下，对应参数说明如下：

- **config**：GraphRAG全局配置对象，提供模型、分词器、Global Search 参数及提示词路径等。
- **entities**：实体表 DataFrame（来自索引表`entities`）。
- **communities**：社区表 DataFrame（来自索引表`communities`）。
- **community_reports**：社区报告表 DataFrame（来自索引表`community_reports`）。
- **community_level**：搜索使用的社区层级；动态选择开启时作为可搜索的最大层级上限。
- **dynamic_community_selection**：是否启用动态社区选择，替代固定层级下使用全部社区报告。
- **response_type**：期望的最终回答形态，传给Reduce提示词控制输出风格。
- **query**：用户查询字符串，用于流式Global Search。
- **callbacks**：查询回调列表，用于在 Map/Reduce 各阶段及流式token生成时触发钩子。
- **verbose**：是否以详细模式初始化日志。

```python
def global_search_streaming(
    config: GraphRagConfig,
    entities: pd.DataFrame,
    communities: pd.DataFrame,
    community_reports: pd.DataFrame,
    community_level: int | None,
    dynamic_community_selection: bool,
    response_type: str,
    query: str,
    callbacks: list[QueryCallbacks] | None = None,
    verbose: bool = False,
) -> AsyncGenerator:
    communities_ = read_indexer_communities(communities, community_reports)
    reports = read_indexer_reports(
        community_reports,
        communities,
        community_level=community_level,
        dynamic_community_selection=dynamic_community_selection,
    )
    entities_ = read_indexer_entities(entities, communities, community_level=community_level)
    map_prompt = load_search_prompt(config.global_search.map_prompt)
    reduce_prompt = load_search_prompt(config.global_search.reduce_prompt)
    knowledge_prompt = load_search_prompt(config.global_search.knowledge_prompt)
    search_engine = get_global_search_engine(
        config,
        reports=reports,
        entities=entities_,
        communities=communities_,
        response_type=response_type,
        dynamic_community_selection=dynamic_community_selection,
        map_system_prompt=map_prompt,
        reduce_system_prompt=reduce_prompt,
        general_knowledge_inclusion_prompt=knowledge_prompt,
        callbacks=callbacks,
    )
    return search_engine.stream_search(query=query)
```

`global_search_streaming`函数执行流程如下：

- 调用如下三个函数从三个对应的`DataFrame`中读取实体、社区和社区报告列表。
  - read_indexer_entities
  - read_indexer_communities
  - read_indexer_reports
- 调用`load_search_prompt`函数加载Map、Reduce阶段调用LLM的提示词模板，以及用来指导LLM使用外部知识来完善答案的提示词模板；
- 利用上述的索引对象列表和提示词模板，以及相关配置调用`get_global_search_engine`函数将作为搜索引擎的`GlobalSearch`对象创建出来；
- 将查询文本作为参数调用`GlobalSearch`对象的`stream_search`方法，并实时返回响应内容。

采用阻塞式调用的`global_search`方法并不会调用`GlobalSearch`的`search`方法，而是直接调用上面这个`global_search_streaming`方法，并将实时获取的响应内容收集起来，最终作统一响应。

```python
async def global_search(
    config: GraphRagConfig,
    entities: pd.DataFrame,
    communities: pd.DataFrame,
    community_reports: pd.DataFrame,
    community_level: int | None,
    dynamic_community_selection: bool,
    response_type: str,
    query: str,
    callbacks: list[QueryCallbacks] | None = None,
    verbose: bool = False,
) -> tuple[
    str | dict[str, Any] | list[dict[str, Any]],
    str | list[pd.DataFrame] | dict[str, pd.DataFrame],
]:
    callbacks = callbacks or []
    full_response = ""
    context_data = {}

    def on_context(context: Any) -> None:
        nonlocal context_data
        context_data = context

    local_callbacks = NoopQueryCallbacks()
    local_callbacks.on_context = on_context
    callbacks.append(local_callbacks)

    async for chunk in global_search_streaming(
        config=config,
        entities=entities,
        communities=communities,
        community_reports=community_reports,
        community_level=community_level,
        dynamic_community_selection=dynamic_community_selection,
        response_type=response_type,
        query=query,
        callbacks=callbacks,
    ):
        full_response += chunk
    return full_response, context_data
```

在如下的演示程序中，我们定义了一个派生于`LiteLLMCompletion`的`TraceableLLMCompletion`类型，并通过重写的`completion_async`方法将LLM调用的请求和响应内容输了出来。我们最终调用`register_completion`函数对`TraceableLLMCompletion`进行了全局注册。

```python
import asyncio
from typing import override,Unpack,AsyncIterator, cast
from graphrag.config.load_config import load_config
from graphrag_llm.completion.lite_llm_completion import LiteLLMCompletion
from graphrag_llm.completion.completion_factory import register_completion
from graphrag_llm.config.types import LLMProviderType
from graphrag_llm.types import (
        LLMCompletionArgs,
        ResponseFormat,
    )
from graphrag_llm.types import LLMCompletionChunk, LLMCompletionResponse
import graphrag.api as api
from graphrag.config.load_config import load_config
import pandas as pd

class TraceableLLMCompletion(LiteLLMCompletion):
    llm_calls: int
    @override
    async def completion_async(
            self,
            /,
            **kwargs: Unpack["LLMCompletionArgs[ResponseFormat]"],
        ) -> "LLMCompletionResponse[ResponseFormat] | AsyncIterator[LLMCompletionChunk]":
        result = await super().completion_async(**kwargs)
        messages = kwargs.get("messages")
        if type(messages) == "str":
            input = messages
        else:
            input = "\n".join([getattr(message, "content", None) or message["content"] for message in messages]) # type: ignore 

        if(hasattr(result, "content")):
            output = getattr(result, "content")
        else:
            output = ""
            async for chunk in cast(AsyncIterator[LLMCompletionChunk], result):
                for choice in chunk.choices:
                    output+= (choice.delta.content or "" if choice.delta else "")                
        
        print(f"""\
----------input----------
{input}
----------output----------
{output}
        """)
        return await super().completion_async(**kwargs)  # type: ignore

register_completion(LLMProviderType.LiteLLM, TraceableLLMCompletion)

async def main():   
    config= load_config(root_dir="./")
    config.global_search.max_context_tokens = 6000
    result= await api.global_search(
        config= config,
        entities=pd.read_parquet('./output/entities.parquet'),
        communities=pd.read_parquet('./output/communities.parquet'),
        community_reports=pd.read_parquet('./output/community_reports.parquet'),
        community_level=2,
        dynamic_community_selection=False,
        response_type="Single Sentence",
        query= "总结李明为咖啡店所作的促销手段。"
    )
asyncio.run(main())
```
