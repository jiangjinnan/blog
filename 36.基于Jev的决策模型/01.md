# [基于JEV的决策模型-01]利用概率回答四种典型的问题

TypeSafe AI是一家由前OpenAI核心研究员创立的AI公司，它们在2026年9月提出了**System One Models**这一工程概念，用于指代专为软件自动化设计、只输出带校准概率的结构化决策（而非自由文本）的新一代模型。这个命名的灵感来自心理学家丹尼尔·卡尼曼的理论，他将**System One**称为快速、直觉、自动的，System Two则表示缓慢、费力、逻辑的推理）。Jev则是该品类下的首个公开旗舰产品，是公司将这一理念落地的第一代商业模型。

## 1. 与LLM的不同之处

Jev彻底放弃了自然语言生成能力，专注于高速、低成本的结构化判断。与传统的文本生成大模型（LLM）相比，Jev具有以下核心差异：

- **输出形式不同**：传统LLM通过自回归逐字生成自然语言或文本，软件需二次解析且易产生格式幻觉。Jev跳过文本生成，通过并行采样直接输出强类型的选择、评分及是非判断，并附带经过校准的置信度概率。
- **效率与成本悬殊**：无需逐个预测词元（Token）使Jev的推理延迟降至70–500毫秒，在分类与路由任务上的速度比传统LLM快40至200 倍，综合成本降低高达400倍（且输出免费）.
- **应用场景互补**：文本生成模型擅长开放式创作与深度推理（类似人类的**System Two**慢思考），而Jev则充当软件自动化与智能体（Agent）工作流中高频、确定性分支判断的快速**System One**反射弧。

顺便说一下，**Jev**这个名字直接取自19世纪经济学家威廉·斯坦利·杰文斯（William Stanley Jevons），以及他提出的**杰文斯悖论（Jevons paradox）**。杰文斯悖论的核心观点是：当某种资源的使用效率提高、成本下降时，社会对它的总需求量反而会增加，而不是减少。TypeSafe 用这个名字来命名他们的模型，是在表达一个明确的商业与技术判断：如果机器做决策的成本能降到极低，那么软件和自动化系统中被解锁的决策需求会爆炸式增长，而不是仅仅替代掉原本由大模型完成的少量判断。Jev 被设计成廉价、快速的决策模型，正是为了承接这种预期中激增的**决策吞吐量**。

## 2. 利用概率回答四类问题

Jev利用经过校准的概率（Calibrated Probabilities）和置信度，专门回答四类强类型原子问题（Primitives）：Choice（多选分类）、Score（量表评分）、Noul（是非概率）以及Box（图像空间定位）。根据TypeSafe官方文档，开发者在一次API请求中可以混合组合这四种问题原语，模型会并行计算并直接返回结构化的数值与概率分布。


| 问题类型 | 核心目标 | 返回的概率与数值字段 | 典型业务场景 |
| :--- | :--- | :--- | :--- |
| **Noul（是非概率）** | 判断某个单一的二元陈述或条件是否为真（Yes/No）。 | 答案为“Yes”的**单一校准概率**（`noul`，取值 0到1）。 | 识别用户是否要求退款、检测消息是否包含个人隐私数据（PII）。 |
| **Choice（多选分类）** | 从预设的封闭集合（最多255项）中选出唯一最佳匹配项。 | 选中项（`choice`）、**所有选项的概率分布**（`probabilities`）、整体置信度（`confidence`）。 | 客服工单路由、意图识别、文档自动归档。 |
| **Score（量表评分）** | 评估状态在有序等级标尺（如1到5级）上的具体位置。 | 期望得分（`score`）、**各等级的概率分布**（`probabilities`）、置信度（`confidence`）。 | 客户愤怒程度评估、候选人简历匹配度打分、事件紧急程度分级。 |
| **Box（图像边界框定位）** | 定位目标物体在输入图像中的具体空间坐标区域。 | 归一化边界框坐标（`top`、`bottom`、`left`、`right`，取值 0到1）及**定位置信度**（`confidence`）。 | 界面元素识别（GUI Agent）、商品缺陷检测、票据关键字段定位。 |

## 3. 一个简单的例子

我们通过一个简单的例子利用TypeSafe SDK（`pip install typesafe-sdk`）针对同一个上下文调用Jev模型并获取除Box之外的三类问题的答案。调用商业模型自然需要对应的API-KEY，我们可以注册到typesafe-ai并利用其[控制台](https://console.typesafe.ai/)创建API-KEY（目前需要提供信用卡进行购买）。如何你只想做一下探索性研究，也可以注册到[openrouter.ai](https://openrouter.ai/)并创建对应的API-KEY，它会提供一些免费的额度，我使用的就是这种方式。

我们创建一个空的Python应用，并在创建的虚拟环境中安装`typesafe-sdk`和`dotenv`，并将获得的API-KEY保存在`.env`中。在如下的演示程序中，我们根据环境变量提供的API-KEY和基于openrouter的URL创建了作为模型调用客户端的`TypeSafeClient`对象，并调用其`system_one`方法调用默认的Jev/System One模型。[基于JEV的决策模型-02：从TypeSafe SDK详细介绍针对Jev模型的调用](https://jaydenai.blog.csdn.net/article/details/170841864)提供了针对`typesafe-sdk`的系统介绍。

```python
import os
from dotenv import load_dotenv
from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

load_dotenv()

with TypeSafeClient(  
    api_key=os.environ["OPENROUTER_API_KEY"],   
    base_url="https://openrouter.ai/api") as client:
    response = client.system_one(
        state= 
            "I've been trying to connect my payment provider for three days and the "
            "integration keeps failing. I'm losing sales. Please help ASAP.",
        questions = {
            "is_urgent": Noul(
                instructions="Does this message convey urgency or time-sensitivity?",
            ),
            "department": Choice(
                instructions="Which team should handle this query?",
                criteria={
                    "billing": "Payment, invoices, refunds",
                    "technical": "Integration, API, configuration",
                    "sales": "Pricing, contracts, new purchases",
                },
            ),
            "frustration": Score(
                instructions="How frustrated does the customer appear?",
                criteria=["calm", "annoyed", "frustrated", "angry"],
            ),
        },
    )

print(f"nouls: {response.nouls}")
print(f"choices: {response.choices}")
print(f"scores: {response.scores}")
```

输出：

```text
nouls: {'is_urgent': NoulAnswer(type='noul', noul=0.98)}
choices: {'department': ChoiceAnswer(type='choice', choice='technical', confidence=0.91, probabilities={'billing': 0.06, 'technical': 0.94, 'sales': 0.0})}
scores: {'frustration': ScoreAnswer(type='score', score=2.05, confidence=0.93, legend={0: 'calm', 1: 'annoyed', 2: 'frustrated', 3: 'angry'}, probabilities={0: 0.0, 1: 0.01, 2: 0.93, 3: 0.06})}
```

我们调用Jev模型旨在针对客户提出的问题：*I've been trying to connect my payment provider for three days and the integration keeps failing. I'm losing sales. Please help ASAP.*）得到如下三种类型的决策，以便于后续对问题的分发处理：

- 问题是否紧急；
- 问题涉及哪些部门；
- 用户的懊恼程度。

我们将客服问题作为调用`system_one`方法的`state`参数，三个不同类型的问题被添加到`questions`参数表示的字典中：

- 是非问题体现为一个`Noul`（类型命名来源于大数学家伯努利的名字，具体应该源自基于二元随机变量的伯努利试验），具体的问题通过`instructions`字段指定:*Does this message convey urgency or time-sensitivity?*。从输出可以看出，判定为紧急的概率为`0.98`，无疑是一个急需马上处理的紧急问题。
- 多类选择问题通过一个`Choice`对象，`instructions`字段设置的指令（Which team should handle this query?）将问题设置为应该选择哪个部分来处理这个问题，具体三个候选部门（`billing`、`technical`和`sales`）对描述的职责通过`criteria`字段指定。这无疑是个计数问题，所以最终选择是`technical`，概率高达`0.94`，其余两个的置信度分别为`0.01`和`0.06`（如果不考虑数据类型的精度，所有选项的置信度加起来应该是`1`）。
- 评分问题属于情感分析，通过一个`Score`对象来表示。我们利用`instructions`字段将问题设置为针对懊恼程度的评分，从低到高设置了`calm`, `annoyed`, `frustrated`, `angry`四个挡位。上面已经说过了，这个得分就是将四个挡位视为随机变量（对应的值为0、1、2和3）的期望值（按照概率加权平均），所以最终得分`2.05`（`=0*0.0 + 1*0.01+2*0.93+3*0.06`）

## 4. 置信度的计算

对于二元的是非问题只需要返回取值为True的概率即可，但是其余两种问题会根据概率分布计算一个置信度，并通过confidence字段返回。

### 4.1 Choice

Choice问题的置信度计算公式为：

$$\text{Confidence} = \frac{n \times p_{\max} - 1}{n - 1}$$

* **$n$**：总选项数量
* **$p_{\max}$**：所有选项中的最高概率值

最终的置信度0.91是通过下面的公式计算出来的：

$$\text{Confidence} = \frac{3 \times 0.94 - 1}{3 - 1} = \frac{2.82 - 1}{2} = \frac{1.82}{2} = \mathbf{0.91}$$

### 4.2 Score

Score置信度三步计算公式

1. **计算实际加权平均距离 ($D_{\text{actual}}$)**：找出概率最高的等级作为峰值 ($\text{peak}$)，计算所有等级 $i$ 到峰值的距离 $|i - \text{peak}|$，并用各自的预测概率 $p_i$ 进行加权求和。
   $$D_{\text{actual}} = \sum_{i} p_i \cdot |i - \text{peak}|$$

2. **计算基准均匀分布距离 ($D_{\text{uniform}}$)**：计算在相同等级数量 $n$ 下，当概率完全均匀分布（每个等级概率为 $\frac{1}{n}$）时，从中间等级 ($\text{mid}$) 到各等级的平均距离（例如 5 个等级时该基准值为 **1.2**）。
   $$D_{\text{uniform}} = \frac{1}{n} \sum_{i=1}^{n} |i - \text{mid}|$$

3. **归一化并得出置信度 ($\text{Confidence}$)**：用 $1$ 减去实际距离与基准距离的比值，若结果小于 $0$ 则截断为 $0$。
   $$\text{Confidence} = \max\left(0,\ 1 - \frac{D_{\text{actual}}}{D_{\text{uniform}}}\right)$$

针对演示实例的概率分布`{0: 0.0, 1: 0.01, 2: 0.93, 3: 0.06}`，最终的置信度（0.93）是通过如下的步骤计算出来的：

#### 确认基础参数

- **等级列表 ($i$)**：$0, 1, 2, 3$（共 $n = 4$ 个等级）
- **对应概率 ($p_i$)**：$p_0 = 0.0$，$p_1 = 0.01$，$p_2 = 0.93$，$p_3 = 0.06$
- **峰值等级 ($\text{peak}$)**：概率最大的等级为 **$2$**（最高概率 $p_2 = 0.93$）

---

#### 三步计算过程

- **计算实际加权平均距离 ($D_{\text{actual}}$)**：
   $$D_{\text{actual}} = (0.0 \times |0 - 2|) + (0.01 \times |1 - 2|) + (0.93 \times |2 - 2|) + (0.06 \times |3 - 2|)$$
   $$D_{\text{actual}} = (0.0 \times 2) + (0.01 \times 1) + (0.93 \times 0) + (0.06 \times 1) = 0 + 0.01 + 0 + 0.06 = \mathbf{0.07}$$

- **计算基准均匀分布距离 ($D_{\text{uniform}}$)**：
   共 $4$ 个等级，中心点 $\text{mid} = \frac{0 + 1 + 2 + 3}{4} = 1.5$。
   $$D_{\text{uniform}} = \frac{|0 - 1.5| + |1 - 1.5| + |2 - 1.5| + |3 - 1.5|}{4} = \frac{1.5 + 0.5 + 0.5 + 1.5}{4} = \frac{4.0}{4} = \mathbf{1.0}$$

- **归一化并得出置信度 ($\text{Confidence}$)**：
   $$\text{Confidence} = \max\left(0,\ 1 - \frac{D_{\text{actual}}}{D_{\text{uniform}}}\right) = \max\left(0,\ 1 - \frac{0.07}{1.0}\right) = 1 - 0.07 = \mathbf{0.93}$$
